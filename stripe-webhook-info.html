Configuration sécurisée des paiements

Webhook Stripe

✓ La fonction serveur Stripe existe déjà.

Elle est destinée à enregistrer les abonnements et dons dans la base INDAMORA PLAY.

Adresse du webhook

https://adqsdnqkbitplbhbihiv.supabase.co/functions/v1/stripe-webhook

Événements nécessaires

  • checkout.session.completed
  • customer.subscription.updated
  • customer.subscription.deleted
  • invoice.payment_failed

Association avec le compte visiteur

Les Payment Links utilisent le paramètre client_reference_id.

Il permet de rattacher le paiement au compte INDAMORA PLAY connecté.

⚠️ Ne jamais mettre une clé secrète Stripe dans un fichier HTML.

Étape restante

Dans Stripe, il faut maintenant créer/activer le webhook avec l'adresse ci-dessus et récupérer son Signing secret.

Ce secret devra rester uniquement côté serveur Supabase.
